# Study Tracker

A full-stack study tracking application built with FastAPI and React.

## Features

* Log study sessions
* Track study hours
* Organize subjects and topics
* View study statistics
* Store data using SQLite

## Tech Stack

### Backend

* FastAPI
* SQLAlchemy
* SQLite
* Pydantic

### Frontend

* React
* TypeScript
* Vite
* Axios

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
